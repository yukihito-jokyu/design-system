# EmptyState

- Registry: `@yukihito/empty-state`
- Source: `src/components/character/empty-state.tsx`

## 導入

```sh
npx shadcn@latest add @yukihito/empty-state
```

## 使用例

```tsx
import { EmptyState } from "@/components/character/empty-state";

<EmptyState title="まだ項目がありません" description="最初の項目を作成してください。" />;
```

必要な状態・Propsは導入後の型定義で確認し、Tokenとアクセシビリティ属性を維持する。
