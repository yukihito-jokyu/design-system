# InputGroup

- Registry: `@yukihito/input-group`
- Source: `src/components/ui/input-group.tsx`

## 導入

```sh
npx shadcn@latest add @yukihito/input-group
```

## 使用例

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupText,
  InputGroupInput,
  InputGroupTextarea,
} from "@/components/ui/input-group";

<InputGroup />;
```

必要な状態・Propsは導入後の型定義で確認し、Tokenとアクセシビリティ属性を維持する。
