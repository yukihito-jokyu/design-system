# Spinner

- Registry: `@yukihi/cobalt-spinner`
- Source: `registry/cobalt/ui/spinner/spinner.tsx`

## 導入

```sh
npx shadcn@4.21.0 add @yukihi/cobalt-spinner
```

## 使用例

```tsx
import { Spinner } from "@/components/ui/spinner";

<Spinner />;
```

アプリを[Provider](../theme-provider.md)で囲み、必要な状態・Propsは導入後の型定義で確認する。Tokenとアクセシビリティ属性を維持する。
