# Toggle

- Registry: `@yukihi/cobalt-toggle`
- Source: `registry/cobalt/ui/toggle/toggle.tsx`

## 導入

```sh
npx shadcn@4.21.0 add @yukihi/cobalt-toggle
```

## 使用例

```tsx
import { Toggle } from "@/components/ui/toggle";

<Toggle />;
```

アプリを[Provider](../theme-provider.md)で囲み、必要な状態・Propsは導入後の型定義で確認する。Tokenとアクセシビリティ属性を維持する。
